#  Autoškola Triumf – Návrh webových stránek -> https://rocnikovka-swa-2.vercel.app/

##  Úvod
Tento projekt představuje návrh struktury webových stránek pro fiktivní autoškolu *Triumf*.  
Cílem je vytvořit přehledný web s minimálně 10 podstránkami, který obsahuje blog, kontaktní formulář a další povinné sekce.

##  Home
Hlavní stránka slouží jako úvod do webu. Obsahuje:
- krátké představení autoškoly  
- hlavní výhody a nabídku služeb  
- navigaci na důležité podstránky  
- ilustrační obrázek  

---

##  O nás
Sekce představuje autoškolu:
- Jak probíhá výuka -> popis výuky teorie, jízd a průběhu závěrečných zkoušek 
- Blog a recenze -> recenze našich žáků a aktuální informace o autoškole
- Instruktoři -> představení našich instruktorů

---

##  Kurzy
Přehled nabízených kurzů s odkazy na podstránky jednotlivých kurzů:
- skupina B –> popis podmínek pro přijetí a splnění kurzu, cena, vozidla atd.
- skupina A –> popis podmínek pro přijetí a splnění kurzu, cena, vozidla atd.
- skupina C -> popis podmínek pro přijetí a splnění kurzu, cena, vozidla atd.
- skupina D -> popis podmínek pro přijetí a splnění kurzu, cena, vozidla atd.
- skupina T -> popis podmínek pro přijetí a splnění kurzu, cena, vozidla atd.

Popis průběhu kurzu:
1. Teoretická výuka  
2. Praktické jízdy  
3. Závěrečná zkouška

##  Závěr
Projekt splňuje všechny požadavky zadání:
- obsahuje více než 10 podstránek  
- zahrnuje povinné sekce (Kontakt, Blog, O nás)  
- obsahuje návrh formulářů  
- obsahuje tabulky (ceník, rozvrh)  
- struktura odpovídá zvolenému tématu autoškoly  
- dokumentace je zpracována ve formátu Markdown
